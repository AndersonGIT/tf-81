// 04 — COMPONENTES

Botões

Hierarquia visual clara: primário para ações de missão, secundário para confirmações, ghost para ações neutras, danger para ações destrutivas.

VARIANTES
TAMANHOS

Cards

Quatro variantes: base para conteúdo geral, command para painéis com autoridade, intel para dados táticos em glass, stat para métricas e operator para perfis de membros.

Relatório Padrão

Card base para conteúdo geral do sistema. Use para listar informações e dados não críticos.

PAINEL DE COMANDO
Estado-Maior

Card com autoridade máxima. Bordas táticas nos cantos inferiores. Usado para painéis administrativos.
